# Team Log: brief

## Purpose
(Write your real reason in your own words. For example: I play each main Pokémon game and want
one place to record my final six, the moves they used, and my notes, so I can pick up each
generation later.)

## Audience
Me first. Anyone who plays through the games and keeps a team record.

## Requirements
Must: browse Pokémon by generation; start a playthrough for a game; six team slots;
up to four moves and a note per team member; notes per playthrough; data saved in the browser;
works on phones; keyboard accessible
Should: search; export and import a backup; overview of runs per generation
Could: caught checklist; type chart; team stats

## Out of scope
Accounts, a server, syncing between devices, battle simulation.

## Data and credits

Passes the HTML validator; WAVE 0 errors; Lighthouse 90+ in all four categories;
passes my test table.
